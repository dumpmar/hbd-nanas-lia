# 🎂 Website Ucapan Ulang Tahun Pink 🎂

Website ucapan ulang tahun yang indah dengan tema warna pink dan animasi yang menarik.

## 🌟 Fitur Utama

- **Desain Pink Cantik**: Gradasi warna pink yang lembut dan menawan
- **Animasi Interaktif**: 
  - Kue ulang tahun dengan lilin berkedip
  - Balon yang mengambang dan bisa diklik
  - Hati-hati yang melayang
  - Konfeti yang jatuh
- **Efek Visual**: 
  - Sparkle saat gerak mouse
  - Animasi kartu masuk
  - Efek glow pada teks utama
- **Responsive Design**: Tampil sempurna di desktop, tablet, dan mobile

## 🎮 Cara Menggunakan

1. **Buka File**: Double-click file `index.html` untuk membuka website
2. **Interaksi**:
   - Klik balon untuk efek meledak
   - Double-click layar untuk pesan perayaan
   - Klik kue untuk efek bounce
   - Gerakkan mouse untuk efek sparkle
   - Tekan Spasi untuk hujan konfeti
   - Tekan Enter untuk efek zoom
   - Tekan H untuk hujan hati

## 📁 Struktur File

```
hbdlia/
├── index.html      # File HTML utama
├── style.css       # File styling dengan tema pink
├── script.js       # File JavaScript untuk interaktivitas
└── README.md       # File dokumentasi ini
```

## 🎨 Customisasi

Anda bisa mengubah:
- **Warna**: Edit nilai warna di `style.css` (cari kode warna pink)
- **Pesan**: Ubah teks di `index.html` bagian `<div class="message">`
- **Nama**: Ganti "Selamat Ulang Tahun!" dengan nama orang spesial
- **Durasi Animasi**: Sesuaikan waktu animasi di `style.css`

## 💻 Persyaratan

- Browser modern (Chrome, Firefox, Safari, Edge)
- Tidak memerlukan instalasi tambahan

## 🎵 Tambahan (Opsional)

Untuk menambahkan musik latar:
1. Tambahkan file audio bernama `birthday.mp3` di folder yang sama
2. Uncomment kode audio di `index.html`
